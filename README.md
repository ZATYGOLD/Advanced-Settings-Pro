# Zatygold's Advanced Settings Pro

This mod expands the game setup for Single player and Multiplayer by adding a bunch of extra options to the Advanced Settings menu. It lets you fine-tune things that normally aren’t adjustable by giving you more configuration choices.

## Version 0.5.0

## New Advanced Settings

- Single Player No Age Transitions: Enabled or Disabled
- Disaster Frequency: Disabled, Light, Moderate, or Catastropic
- Settler Movement: Slow, Default, or Fast
- Treasure Convoy Movement: Slow, Default, or Fast
- Military Unit Cost: Cheaper, Default, or Expensive
- Natural Wonders: None, Half, Default, More, or Double
- Lake Generation: Less, Default, or More
- Crisis Speed (Pacing): Crawl, Slow, Default, Quick, or Fast
- Settlement Limit: Less, Default, or More
- Settlement Distance: Less, Default, or More
- Independent Power Spacing: Less, Default, or More
- Independent Power Initial Unit Amount: Less, Default, or More

## Languages

- English
